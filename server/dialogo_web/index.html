Diálogo com várias vozes

Escreva as falas como Nome: fala, escolha uma voz para cada personagem e gere um áudio só (com a legenda).

Uma fala por linha, no formato Nome: fala. Linhas sem nome usam a voz do Narrador. Uma linha em branco separa os blocos (pausa maior). Pausas: <pause 1s>. Limite: 200.000 caracteres e 2.000 linhas.
O tom só funciona em vozes sem transcrição (as vozes padrão e as suas clonadas sem transcrição). Personagens sem a marca "é personagem" ficam como texto comum, lido pelo Narrador.
